## Failure history and fixes

1. The first validator attempt stopped after CTest because `set -u` expanded an unset `NO_PROXY`. The script now safely handles unset upper- and lower-case variables while adding loopback exclusions.
2. A sandboxed attempt could not write the pinned Flutter cache (`Operation not permitted`). The same command was rerun with the required host permission; this was an execution-environment failure, not a code failure.
3. The first macOS build attempt reported missing CocoaPods. CocoaPods 1.17.0 was installed only after user approval, then the complete validator was rerun.
4. The initial phone-sized simulator layout produced a vertical `RenderFlex` overflow. A minimal responsive layout switches the workspace to Scene / Preview / Controls tabs on compact widths, and a 430 x 932 widget regression test was added.
5. The media page used nested vertical scroll views on compact screens, causing drag rebound and making the opacity slider unreachable. Compact mode now has one vertical scroll owner; a phone-sized drag/slider regression test was added. Wide layouts retain independent panels.
6. Initial device signing could not create a profile with the first saved Personal Team selection. The saved Flutter signing selection was cleared and the user selected the second available team. The original bundle identifier then signed and installed successfully. No account name, certificate identity, device identifier, or provisioning profile is recorded here.
