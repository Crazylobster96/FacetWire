### 首条真实错误与最小复现

最小复现命令：

```sh
cmake --build build/chart-v03-macos --config Release
```

AppleClang 在 `plugins/hierarchical_chart_renderer/tests/hierarchical_chart_renderer_test.c` 报告 `missing field ... initializer [-Werror,-Wmissing-field-initializers]`。根因是测试用例使用 `{sizeof(value)}` 只初始化结构体首字段，而工程把警告作为错误。修复将对象先以 `{0}` 完整清零，再显式设置 `struct_size`；没有修改渲染器、数据、主题、布局、标签、ABI 或演示行为。

Simulator Release 失败的最小复现命令是 `flutter build ios --simulator --release`，首条错误为 `Release mode is not supported for simulators.`。这是 Flutter 工具模式限制，不是产品失败；正式 iOS Release `--no-codesign` 与 Simulator Debug 均已通过。
