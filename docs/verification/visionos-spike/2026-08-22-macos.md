## 本轮缺陷与修改

本轮只修改 visionOS 工程生成配置及其精确忽略规则：

1. `spikes/visionos_host/apple/project.yml`
   - 为测试目标补充共享 C Header Search Paths，修复 bridging header 依赖扫描失败；
   - 由 XcodeGen 生成 Info.plist，并声明 `UIApplicationSupportsMultipleScenes = true`，修复 volume 无法打开；
   - 保留 `MARKETING_VERSION` 与 `CURRENT_PROJECT_VERSION` 的版本映射。
2. `.gitignore`
   - 仅忽略 XcodeGen 生成的 visionOS `.xcodeproj` 和 Info.plist；生成物仍保留在本机。

未修改共享 C Bridge、DisplayList Decoder、FacetWire Core ABI、Flutter 或既有 macOS/iOS Runner，因此无需补跑 macOS/iOS 定向回归。
