# FacetWire 图表视觉设计系统 0.4

[English](chart-visual-design-system-v0.4.md) | **简体中文**

状态：实现基线草案
范围：Core Chart Renderer、Hierarchical Chart Renderer 与 Playground Draw Sink
兼容性：仅增加视觉策略，不修改 Chart ABI 或持久化场景 Schema

## 1. 目标

Chart Visual Design 0.4 为全部 FacetWire 图表类型定义一致的展示系统，并将持久化图表语义与宿主交互分离：

- Renderer 主题层负责语义色、前景色、网格、间距与标记密度；
- 跨平台 Draw Sink 负责设备像素相关的圆角、平滑描边与系统无衬线字体栅格化；
- 交互宿主负责悬浮、触控状态和临时 Tooltip 表面。

因此同一图表文件仍然可确定地跨平台渲染，而桌面鼠标、触控屏和空间设备可以提供各自合适的交互方式。

章节检查：职责边界明确；临时指针状态不会写入 Agent Scene Package，也不需要扩展 Renderer ABI。

## 2. 设计 Token

### 2.1 色彩角色

| Token | 用途 | Business 基线 |
|---|---|---|
| `chart.foreground` | 标题、坐标轴与标签 | 深灰 `#344052` |
| `chart.grid` | 仅用于主要参考线 | 30% Alpha 的冷灰 |
| `chart.series.primary` | 主要对比系列 | 科技蓝 |
| `chart.series.secondary` | 次要对比系列 | 低饱和蓝绿色 |
| `chart.accent` | 被提升或重要的数据 | 受控的明亮橙色 |
| `chart.surface` | 仅用于 Playground 预览 | 冷调灰白 |

Light、Business 与 Academic 采用低饱和科技蓝、高级灰和莫兰迪色系；Dark 使用柔和且可读的变体。High Contrast 为保证无障碍对比度而有意保留更强颜色。

### 2.2 几何角色

- 笛卡尔绘图区：左 12%、右 12%、上 16%、下 22% 留白；
- 默认柱间距比例：0.32；
- 柱体圆角：`min(6 设备像素, 短边的 16%)`；
- 折线宽度：0.004 归一化单位，并使用圆形端点与连接；
- 面积填充默认不透明度：0.22；
- Tooltip 圆角 12 像素、模糊 sigma 12、阴影模糊 18。

章节检查：每个值都明确属于归一化 Renderer 空间或设备像素 Draw Sink 空间，缩放行为无歧义。

## 3. 图形标记规则

### 3.1 柱形

普通柱图、横向柱图、堆叠柱图、百分比柱图、直方图、瀑布图和对比柱图使用轻微圆角。热力图单元格和矩形树图节点保持直角，避免改变邻接关系与面积感知。

### 3.2 折线

折线图、时间序列、分区折线和组合图中的折线在已输出的数据点之间使用单调三次曲线进行视觉插值。源数据和命中测试锚点不变；坐标轴、网格线和瀑布连接线保持直线。

### 3.3 字体

宿主使用各平台现代系统无衬线字体。标题使用 Semibold，标签使用 Regular；除 High Contrast 外，文字使用主题深灰而非纯黑。

章节检查：规则按图表语义进行限制，不会让装饰性圆角或平滑处理破坏热力单元格、坐标轴或源数据。

## 4. 布局与网格

绘图区相较 0.3 预留更多上下空间。网格仅保留主要参考线，并以低 Alpha 绘制。主题不得添加不透明图表背景；未覆盖像素继续遵守 FacetWire Renderer 的透明契约。Playground 的底色只是宿主预览表面。

章节检查：Renderer 透明度与预览表面颜色被明确划分，避免重新引入“透明图层出现白板”的问题。

## 5. Tooltip 状态

Tooltip 是临时宿主 UI，不是持久化场景中的图表元素。鼠标悬浮与触控点击依据已渲染命令几何执行命中测试，并排除网格与坐标轴参考线。Tooltip 展示命令标签以及可获得的系列、分类和数值标签信息。

视觉状态：

- 半透明深灰表面；
- 12 像素背景模糊与轻阴影；
- 12 像素圆角和微弱白色边框；
- 白色标题与柔和灰色详情；
- 始终限制在图表视口内，不得污染控制区或侧栏。

章节检查：桌面悬浮与触控点击均受支持；Tooltip 被视口裁剪，也不会改变确定性渲染输出。

## 6. 无障碍与降级

- High Contrast 保留更强配色，并在必要时使用纯黑前景色；
- Tooltip 不应成为未来唯一的信息路径，语义树和键盘焦点仍是非指针访问的权威路径；
- 不支持背景模糊的平台仍可用半透明深灰表面保持可读性；
- 小标签继续服从 Presentation 的碰撞避让与标签策略。

章节检查：视觉美化不会替代语义、对比度或非指针访问，并定义了可用的降级行为。

## 7. 兼容性与扩展

0.4 只修改主题 Token 值与宿主绘制策略。现有图表类型、系列、分类、元素 ID、Cache Key 输入、元素覆盖以及保存文件继续有效。未来可以通过新增样式 ABI 暴露圆角、插值与 Tooltip 内容策略，但必须以本基线作为默认值并保持增量兼容。

最终一致性检查：配色、几何、标记规则、交互职责、透明度与无障碍组成一套一致的分层结构。层级图与笛卡尔图共享颜色角色，同时保留不同几何语义；这些规则只控制展示，不修改数据源，因此不会与 VisualTransform、元素图层覆盖、Flow Layout 或未来 FacetWire-Forge 编辑能力冲突。
