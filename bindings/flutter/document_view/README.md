# FacetWire Flutter document view 0.1

Reusable DOCX measurement/painting and PDFium fixed-page adapter. The host supplies a `DocumentFlowComposer` and owns the returned document's lifetime. Unpainted areas are transparent by default; paper background is an explicit host option.

See the [user guide](../../../docs/guides/document-import-user-guide.zh-CN.md). Real PDFium, native Flow and widget integration tests live in `examples/placeholder_demo/test/document_import_test.dart`.
