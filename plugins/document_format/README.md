# FacetWire document format reference 0.1

Pure Dart DOCX importer and shared read-only document model. This is not yet a C ABI format plugin. PDF adaptation lives in `bindings/flutter/document_view`; XLSX/PPTX identifiers are reserved but unsupported.

See [design](../../docs/design/document-format-plugins-v0.1.zh-CN.md) and [user guide](../../docs/guides/document-import-user-guide.zh-CN.md).

Run `dart pub get`, `dart analyze`, and `dart test` here. Tests use the repository's original DOCX fixture. Input packages are never extracted to user directories or overwritten.
